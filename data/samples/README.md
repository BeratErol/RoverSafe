# Sentetik deneme görüntüsü

`synthetic_terrain.png`, `scripts/create_sample.py` tarafından sabit rastgelelik
tohumuyla üretilir. Gürültü azaltma ve dosya akışını denemek içindir.
Gerçek drone görüntüsü, etiketli veri seti veya güvenli zemin örneği değildir.

Yeniden üretmek için proje kökünde:

```powershell
python scripts/create_sample.py
```
